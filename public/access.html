If DNS is poisoned or blocked

Use DNS-over-HTTPS (DoH) so your resolver cannot lie about where tukuk.org lives:

  1. Firefox: Settings → Privacy & Security → DNS over HTTPS → enable → choose Cloudflare (1.1.1.1) or Google (dns.google).
  2. Chrome/Edge: Settings → Privacy and security → Security → Use secure DNS → pick a provider.
  3. Mobile: install the 1.1.1.1 app (Cloudflare WARP) or set a private DNS name (one.one.one.one / dns.google) in Android settings.

If Tor itself is blocked

Tor Browser supports bridges — entry points that are not publicly listed:

  1. Tor Browser → hamburger menu → Configure Connection → Use a bridge.
  2. Enable Request a bridge (built-in obfs4) or get bridges from bridges.torproject.org and paste them in.
  3. Then open the onion address above as usual.

Honest limits

No service on Earth can promise it will never be blocked — any government can filter a domain, an IP or even a TLS fingerprint. What Tukuk-OS does instead is keep several independent doors open: an anycast main domain, a Tor onion service, and a mirror on a separate domain. If one door closes, another one leads to exactly the same site.
