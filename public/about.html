Tukuk-OS is a web search engine for the domain tukuk.org. It is built to search public web pages in Malay and English, with a focus on answer quality and source transparency.

How it works

LayerRole
MeilisearchStores and builds the inverted index. Runs on port 7700.
API serverNode.js + Express, port 8000. Provides search, crawler, and API.
CrawlerOwn code. Respects robots.txt and avoids internal addresses.
BrainSmall language model through Ollama. Builds answers from the sources it finds.

Search features

  • Word highlighting and snippets with context
  • Automatic typo tolerance
  • Malay synonyms (cari, carian, pencarian, geledah)
  • Facets: site, language, content type
  • Filters for time, word count, and domain
  • Autocomplete suggestions

Privacy and transparency

Every answer from the brain includes a list of source URLs. If there are not enough sources, the system is honest and says that it does not know — it does not invent facts.
