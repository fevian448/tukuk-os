1. Introduction

Tukuk-OS is an independent and intelligent web search engine platform built on the high-performance Meilisearch indexing core, Node.js, and a semantic RAG model (Retrieval-Augmented Generation). Tukuk-OS is designed specifically to deliver fast search that respects user privacy and enables distributed data integration.

2. REST API reference

All API responses are returned in standard JSON format with CORS headers automatically allowed.

GET /search

Runs a full-text search over the web index with advanced filtering, facets, and keyword highlighting.

ParameterTypeDescription
qStringPrimary search keywords (example: teknologi).
limitIntegerMaximum number of records to return (default: 20).
offsetIntegerRecord offset for the paging / pagination system.
langStringDocument language filter (example: ms, en).
indexStringOptional test corpus index. Only uji_coba is accepted; any other value falls back to the live index halaman_web.
curl -s "https://tukuk.org/search?q=carian&limit=5"
curl -s "https://tukuk.org/search?q=carian&index=uji_coba"

GET /health

Checks the server health status, uptime, the Meilisearch database connection, and crawler statistics.

curl -s "https://tukuk.org/health"

GET /stats

Returns overall metrics such as the total number of indexed documents, database size, and server memory usage.

3. Protocol & Web Crawler

The Tukuk-OS web crawler scans links in line with international web etiquette standards:

  • Follows the robots.txt file of every domain before starting a crawl.
  • Uses a politeness delay to avoid overloading target servers.
  • Cleanly extracts OpenGraph metadata, titles, descriptions, and the document body text.

4. Security & Privacy

Tukuk-OS does not track or store personal user profiles. All search data is processed without any third-party trackers that intrude on your privacy.
