Paste an IP address that claims to be Bingbot (for example one from your server logs) and check it against Microsoft's official method. If nothing is entered, your own IP is checked.

Try the sample above: a live Bingbot address from Microsoft's published ranges.

    How verification works

    1. Reverse DNS — the hostname for the IP must end in .search.msn.com.
    2. Forward-confirmation (FCrDNS) — that hostname must resolve back to the same IP.
    3. Published list — Microsoft also publishes its crawl ranges at bing.com/toolbox/bingbot.json; IPs there are accepted even when reverse DNS is missing (some Bingbot subnets publish no PTR records).

    Result not matching your logs? Report a false positive or false negative through Bing Webmaster Tools → Tools & Enhancements → Verify Bingbot, or read How to Report an Issue with Bingbot.

    Reference: How to verify Bingbot · Bing's own tool · our API

    API

    GET /api/bingbot?ip=157.55.39.212 — omit ip to check the caller's IP (via CF-Connecting-IP).

    Response: verdict (verified, mismatch, not-bingbot, inconclusive), rdns, forward, publishedList.
